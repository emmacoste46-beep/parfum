# Amora — lancement parfum

Landing page Next.js avec Tailwind CSS, Motion, Three.js, LottieFiles et Lucide.

Node.js 20.9 ou supérieur est requis.

```bash
npm install
npm run dev
```

Déposez le modèle fourni dans `public/assets/parfum.glb`. La scène le charge au démarrage et fait tourner le flacon au fil du scroll. Un flacon 3D intégré sert de relais en l’absence du GLB.
